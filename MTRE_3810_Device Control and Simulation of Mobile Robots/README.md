# MTRE 3810 – Device Control and Simulation of Mobile Robots

Selected projects completed independently for MTRE 3810 at Kennesaw State University.

## Features

* ROS
* Mobile Robot Navigation
* Robot Simulation
* Motion Control
* Autonomous Navigation

## Projects

### ROS Autonomous Mobile Robot Navigation

> This homework focused on implementing SLAM and Path Planning using ROSBOT 2.0 in the Gazebo simulator. The robot was configured, used for mapping, and performed autonomous navigation. The system was verified using ROS tools including tf, rqt, ROS services, ROS actions, ROS bag, and ROS time.


**Keywords:** ROS, SLAM, autonomous navigation, path planning, mobile robotics, robot localization, Gazebo simulation, RViz, ROS navigation stack, occupancy grid mapping.

### Custom ROS Wheeled Robot

> This assignment focused on modifying a URDF robot using xacro files and controlling the robot using a C++ ROS program. The robot was modified into a wheeled design by replacing the cylindrical arms with wheels. A ROS publisher node was implemented to control robot movement in Gazebo simulation.
**Keywords:** ROS, URDF, Xacro, Gazebo, C++, mobile robotics, robot modeling, robotic control, simulation, ROS publisher
