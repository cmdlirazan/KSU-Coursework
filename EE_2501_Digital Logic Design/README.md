## Projects

### Dual-Mode Soil Moisture–Based Irrigation System Using Digital Logic

> This project presents a dual-mode irrigation system that automates plant watering using digital logic and an Arduino Uno. The system operates in either manual or automatic mode by combining user input with soil moisture data through a Boolean logic expression. The analog moisture reading is converted into a binary condition (M) by comparing the ADC value with a predefined threshold. The system was validated in Tinkercad before implementation on physical hardware. Testing demonstrated reliable operation in both manual and automatic modes, showing the practical application of digital logic and embedded programming in an automated irrigation system.

**Keywords:** Arduino Uno, Digital Logic, Boolean Algebra, Embedded Systems, Irrigation System, Relay Module, Soil Moisture Sensor
